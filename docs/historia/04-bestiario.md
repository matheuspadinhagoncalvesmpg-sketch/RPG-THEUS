# 04 · Bestiário: os Esquecidos

> *"Não existem monstros em Vésper. Existem pessoas que esqueceram onde estavam indo."*
> — Oren

## 1. A regra dos Esquecidos

Um **Esquecido** é alguém cuja **lanterna apagou**. A pessoa continua existindo, mas **sem ninguém dentro**: repete **um hábito** de quando estava inteira, e esse hábito é o que o jogador vê como "comportamento do monstro".

**Por que atacam o herói?**
Porque o herói **carrega luz** (a lembrança de Alva), e Esquecidos são atraídos por qualquer luz **na esperança de lembrar**. Só que não conseguem *segurar* a luz: o contato **queima os dois**. Eles não querem machucar. **Querem lembrar, e isso machuca.**

**Por que caem moedas?**
Cada Esquecido carrega **o último Dízimo que pagou** (moedas da Aurora). Quando cai, a moeda cai junto. *Mira vai saber de quem era.*

**Por que ALMA enche ao ferir?**
Cada golpe **solta uma lembrança** do Esquecido, uma imagem, um cheiro, uma voz. O herói a **recolhe**. Curar é *segurar essa lembrança no peito até ela esquentar*. Por isso Mira e o Eco avisam: *"Quem cura com o que tomou, deve devolver."*

### Duas regras de design
1. **O comportamento do monstro deve ser o hábito dele**, nada mais. Se uma ação não puder ser explicada como hábito de uma profissão ou de uma brincadeira, o monstro está errado.
2. **A Chama da Alma mostra a verdade.** Quando a magia acerta um Esquecido, ele **pisca por um instante** na forma de quem foi (uma silhueta clara, humana). Dói porque é real.

## 2. As seis espécies

### 2.1 Gosma (*Os Que Seguem a Rota*)

| | |
| :--- | :--- |
| **Eram** | **Trabalhadores**: colhedores nos Campos, mineiros nas Cavernas, carregadores. |
| **Onde** | Campos, Cavernas de Cristal, Raízes. |
| **Aparência** | Massa translúcida, **da cor do lugar** onde se perdeu (a gosma "absorve" a luz ao redor). |
| **Hábito que repete** | **Caminhar de ida e volta** pelo mesmo trajeto, virando nas beiradas, como quem **volta pra casa**. |
| **Por que é lento** | Quem repete uma rota não tem pressa. |
| **Por que "virar na beirada"** | Era onde a estrada acabava. |

> **Verbete:** *Fazem o mesmo caminho há quatrocentos anos. Se você ficar parado no meio dele, eles te contornam. Se você os empurra, pedem desculpa sem saber a quem.*

**O que Mira sabe:** *"Esses pagavam em trigo. Eram os primeiros da fila."*

---

### 2.2 Cogumelo saltitante (*Os Que Brincavam*)

| | |
| :--- | :--- |
| **Eram** | **Crianças** que brincavam ao ar livre no fim do dia quando o sol parou. |
| **Onde** | Campos, Raízes, Galeria Cintilante. |
| **Aparência** | Chapéu vermelho com pintas brancas, rosto **bravo**. |
| **Hábito que repete** | **Amarelinha**: pular em direção ao jogador, *chamando-o para brincar*. |
| **Por que a cara de bravo** | É a cara de **quem foi chamado para casa e não quis ir**. |
| **Por que pula e espera** | Os pulos são **a vez de cada um**. |

> **Verbete:** *Não atacam. Chamam. Mas a brincadeira deles tem regras que ninguém lembra, então acabam de um jeito ruim.*

**Pagamento no final bom:** os cogumelos **voltam para casa**: aparecem pequenos e imóveis, como **cogumelos de quintal**, ao redor do Lar. Um dos poucos sorrisos puros do jogo.

---

### 2.3 Morcego de brasa (*Os Acendedores*)

| | |
| :--- | :--- |
| **Eram** | **Acendedores** (a ordem que acendia as lanternas no fim do dia). A **mãe de Alva, Liora, era uma delas.** |
| **Onde** | Moinho, Orla das Lanternas, Pico, Poço Ecoante, e **no Lar, durante as noites**. |
| **Aparência** | Asas de membrana, olhos de brasa. |
| **Hábito que repete** | **Voar de lanterna em lanterna** (o jogador é uma lanterna). |
| **Por que o brilho nos olhos** | É **o último pavio** que acenderam. |
| **Por que vêm ao Lar** | Sentem a fogueira e **acham que é hora de acender**. |

> **Verbete:** *Não sabem que a hora de acender nunca chegou. Passam o dia esperando o crepúsculo, e o crepúsculo nunca termina.*

---

### 2.4 Flor carnívora (*As Jardineiras*)

| | |
| :--- | :--- |
| **Eram** | **Jardineiras da Rainha**: cuidavam dos jardins do alto, antes de afundarem. |
| **Onde** | Bosque, Cavernas. |
| **Aparência** | Flor rosa de pétalas e dentes. |
| **Hábito que repete** | **Plantar**: cospem **sementes** (a bolha verde) na direção do que se mexe. |
| **Por que só cospe** | Jardineira **não anda**; planta. |
| **Por que "dentes"** | São um **sorriso exagerado**. |

> **Verbete:** *Não é fome: é hospitalidade. Elas querem que você fique para o jantar, e o jantar é você.*

*Ironia deliberada:* a "carnívora" **só quer companhia.**

---

### 2.5 Golem Sentinela (*A Guarda de Pedra*)

| | |
| :--- | :--- |
| **São** | **Construtos**, **não Esquecidos.** Forjados por Tibério e pelos pedreiros da Casa para **guardar o Caminho da Coroa**. |
| **Onde** | Ruínas Suspensas, o Caminho do Trono. |
| **Aparência** | Pedra, musgo, lança, **uma runa no peito**. |
| **Hábito que repete** | **A ordem escrita**: a runa diz **GUARDAR**. |
| **Por que "investem"** | A ordem original era *"impedir a passagem de quem não for da Casa"*. |
| **Por que a runa fica vermelha** | **Reconhecem ameaça**. |

> **Verbete:** *Foram feitos para proteger uma criança. Perderam de vista qual.*

**Segredo para os atentos:** a runa completa é **GUARDAR ALVA**. A segunda palavra está **apagada** pelo tempo. *Eles guardam a criança que não reconhecem mais.*

**Ideia de mecânica narrativa (opcional):** depois de ter o **Manto do Vento**, os golens **hesitam por um segundo** ao ver o herói (a runa pisca azul). Pequeno, perceptível.

---

### 2.6 Peixe-lanterna (*Os Pescadores da Maré*)

| | |
| :--- | :--- |
| **São** | **Mensageiros de Ondina.** Descendentes de peixes comuns **que levam almas até ela**. |
| **Onde** | Jardins Submersos. |
| **Aparência** | Peixe-abissal, **isca luminosa** na ponta da antena. |
| **Hábito que repete** | **Pescar lembranças perdidas** (a isca é uma lanterna de quem se afogou). |
| **Por que atacam o herói** | O herói carrega **uma lembrança inteira de Alva**: o prêmio mais valioso. Eles querem **levá-lo até ela**. Mordem porque não sabem *conduzir* de outro jeito. |

> **Verbete:** *Cada isca é a última luz de alguém. Eles a seguram na frente do rosto para que as almas perdidas os sigam.*

## 3. O que **não** é Esquecido

| Quem | Por que não |
| :--- | :--- |
| **Os três chefes** | São pessoas inteiras, com nome e motivo. |
| **Golens** | Construtos. |
| **Os NPCs** | Pessoas inteiras. |

Isso faz uma diferença de tom: **com os Esquecidos, o jogador sente pena. Com os chefes, sente luto.**

## 4. Variações regionais (a mesma gosma não é a mesma gosma)

Para o mundo parecer vivo, cada espécie ganha um **detalhe local** que conta mais uma coisa:

| Região | Detalhe | O que conta |
| :--- | :--- | :--- |
| **Campos** | Gosma com **fiapos de trigo** | Eram colhedores. |
| **Cavernas** | Gosma com **lascas de cristal** | Eram mineiros. |
| **Bosque** | Cogumelo com **vaga-lume** dentro do chapéu | Brincavam nas lanternas. |
| **Ruínas** | Golem com **musgo grosso** | O alto é úmido: o céu chora. |
| **Jardins** | Peixe com **isca de cor diferente** | Cada isca é uma pessoa. |

---

## 5. Ataques noturnos: *as primeiras noites*

Quando o herói tem uma base habitada, **o Lar ganha noite**. Os Esquecidos, que **esqueceram o escuro**, entram em pânico e correm para o **fogo**.

| Onda | Quem vem | Por quê |
| :--- | :--- | :--- |
| **Cogumelos** | *"Hora de entrar."* | Vêm para casa. |
| **Morcegos** | *"É hora de acender."* | Sentem a fogueira. |
| **Gosmas** | *"Fim da rota."* | Reconhecem **uma casa**. |

**Detalhe emocional:** essas ondas **não são ataques**, são **visitas desesperadas**. O jogo as chama de **ataques** porque **o herói não sabe disso ainda**. Mas, **quanto mais perto do final bom**, mais o texto da narração muda: de *"estão atacando"* para *"estão chegando"*.
